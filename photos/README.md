# Photos

Every image used on the site lives in this folder.

## Replace a photo (easiest method)

Upload a new image using the **same file name**. The site updates automatically, and nothing else needs to change.

| File name              | Where it appears                     | Best shape          |
| ---------------------- | ------------------------------------ | ------------------- |
| `hero.jpg`             | Front cover                          | Tall / portrait     |
| `chapter-hello.jpg`    | Chapter One - Once Upon a Hello      | Landscape           |
| `moments-01..04.jpg`   | Chapter Two - the film strip         | Portrait            |
| `chapter-knew.jpg`     | Chapter Three - the quote background | Wide landscape      |
| `chapter-proposal.jpg` | Chapter Four - The Proposal          | Landscape           |
| `gallery-01..08.jpg`   | The Album                            | Any shape           |

## Add or remove album photos

1. Upload the image into this folder.
2. Open `content/site-content.js`.
3. Add or delete a line in the list.

## Keep the site fast

- Resize photos to roughly 1600-2000 pixels on the longest side.
- Aim for under 500 KB per photo, and under 700 KB for `hero.jpg`.
- Free resizing tools: <https://squoosh.app> or <https://tinypng.com>
- Use `.jpg` names exactly as shown above, in lowercase.

## A note on privacy

This site is public. Avoid uploading photos that contain home addresses,
documents, boarding passes, or anything you would not want shared openly.
